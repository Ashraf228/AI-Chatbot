# Commit And PR Template

Use:
- `AGENTS.md`
- `docs/operations/*`

Inputs:
- `Task: <TASK_ID>`
- `Branch: <branch>`
- `Commit message: <message>`
- `PR title: <title>`
- `PR body summary:`

Instructions:
- confirm the working tree contains only in-scope changes
- state the local checks already completed
- commit exactly the intended scope
- push the branch
- open the PR with scope, safety, and non-goals documented

Output:
1. status
2. branch
3. commit SHA
4. PR URL
5. scope confirmation
6. checks summary
