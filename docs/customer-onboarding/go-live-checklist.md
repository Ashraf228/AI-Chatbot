# Go-Live Checkliste

Stand: 2026-05-28

Operative Checkliste fuer Kunden-Go-live. Keine Rechtsberatung und keine Vertragszusage.

## Technisch

- [ ] Kunde/Site angelegt.
- [ ] Template angewendet.
- [ ] Sub-Branche gesetzt, falls relevant.
- [ ] Domain korrekt gesetzt.
- [ ] Ungueltige Domain wird geblockt.
- [ ] Widget sichtbar.
- [ ] Widget loader laedt.
- [ ] Session startet.
- [ ] `consentRequired` aktiv oder fachlich freigegeben konfiguriert.
- [ ] `privacyUrl` gesetzt.
- [ ] Datenschutzlink erreichbar.
- [ ] Wissensbasis hochgeladen.
- [ ] Knowledge Retrieval getestet.
- [ ] Agenten aktiviert.
- [ ] Lead gespeichert.
- [ ] E-Mail-Zustellung geprueft.
- [ ] Webhook geprueft, falls genutzt.
- [ ] Dashboard zeigt Leads.
- [ ] Dashboard zeigt Conversations.
- [ ] Delivery-Badges sichtbar.
- [ ] Usage sichtbar.
- [ ] Monitoring gruen.
- [ ] Backup gruen.
- [ ] Offsite Backup gruen.
- [ ] Job Health gruen.

## Rechtlich und organisatorisch

- [ ] Impressum vorhanden.
- [ ] Datenschutzerklaerung vorhanden.
- [ ] Chat/Widget in Datenschutzerklaerung erwaehnt.
- [ ] AVV geprueft/unterschrieben.
- [ ] TOMs geprueft.
- [ ] Subprozessoren geprueft.
- [ ] Drittlandtransfer geprueft.
- [ ] Speicherfristen abgestimmt.
- [ ] Kunde kennt Loesch-/Exportprozess.
- [ ] Kunde kennt Supportkontakt.

## Testfragen

- [ ] Preisfrage getestet.
- [ ] Problemfrage getestet.
- [ ] Rueckrufwunsch getestet.
- [ ] Sensible-Daten-Test durchgefuehrt.
- [ ] Einsatzgebiet getestet.
- [ ] Sonstige FAQ getestet.
- [ ] Antworttonalitaet freigegeben.

## Lead-Test

- [ ] Testlead mit klarer TEST-Markierung erzeugt.
- [ ] Lead in Dashboard sichtbar.
- [ ] Lead-Zustellstatus sichtbar.
- [ ] E-Mail/Webhook-Zustellung geprueft.
- [ ] Conversation sichtbar.
- [ ] Testlead geloescht oder klar markiert.
- [ ] Keine echten Testdaten sichtbar.

## Nachbereitung

- [ ] Kunde freigegeben.
- [ ] Datum Go-live: `[DATUM]`
- [ ] Verantwortliche Person Anbieter: `[NAME/ROLLE]`
- [ ] Verantwortliche Person Kunde: `[NAME/ROLLE]`
- [ ] Offene Punkte dokumentiert.
- [ ] Erste 24h Beobachtung eingeplant.
