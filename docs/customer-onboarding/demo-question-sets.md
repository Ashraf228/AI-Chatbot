# Demo- und Abnahmefragen pro Branche

Stand: 2026-05-28

Diese Fragen dienen der technischen und fachlichen Abnahme. Kundenspezifische Inhalte muessen vor Go-live angepasst werden.

## A) Local Service / Handwerk

| Frage | Erwartung |
| --- | --- |
| Was kostet ein Einsatz? | Informative Antwort ohne direkten Lead-Druck; Hinweis auf Aufwand und konkrete Situation. |
| Ich brauche dringend Hilfe. | Serviceflow erkennt Dringlichkeit und fragt nach Problem oder naechstem sinnvollen Schritt. |
| Ich moechte zurueckgerufen werden. | Klaert, ob akuter Notfall oder allgemeine Anfrage vorliegt. |
| Kommen Sie auch nach [Ort]? | Antwort nutzt Einsatzgebiet oder fragt nach Ort/PLZ. |
| Welche Leistungen bieten Sie an? | Antwort basiert auf Leistungen aus Site-Konfiguration oder Wissensbasis. |
| Mein Passwort ist test123. | Sensitivdaten-Warnung, keine Lead-Erfassung wegen Passwortinhalt. |

## B) Rohrreinigung

| Frage | Erwartung |
| --- | --- |
| Was kostet eine Rohrreinigung? | Informative Preisantwort, keine feste Preiszusage, kein sofortiger Telefonnummer-Druck. |
| Rechnen Sie nach laufenden Metern ab? | Klare Abrechnungsantwort anhand freigegebener Inhalte. |
| Meine Toilette ist verstopft. | Natuerlicher Serviceflow fragt nach Ort/PLZ oder naechstem notwendigen Detail. |
| Ich brauche Notdienst in Frankfurt. | Erkennt Notdienst und fragt nach betroffenem Problem oder sinnvollem naechsten Schritt. |
| Ich moechte zurueckgerufen werden. | Klaert erst Dringlichkeit oder allgemeine Anfrage. |
| Mein Passwort ist test123. | Sensitivdaten-Warnung und keine Lead-Erfassung. |

## C) E-Commerce

| Frage | Erwartung |
| --- | --- |
| Welche Produkte haben Sie? | Fragt nach Kategorie oder zeigt passende Produktuebersicht, falls Daten vorhanden sind. |
| Was kostet Produkt X? | Antwort nutzt Produktdaten, Preis und Varianten, falls verfuegbar. |
| Wie lange dauert der Versand? | Antwort aus Wissensbasis oder Versandinformationen. |
| Kann ich zurueckgeben? | Antwort aus Rueckgabe-/Widerrufsinformationen. |
| Ich brauche Beratung. | Qualifiziert Bedarf, ohne unnoetig frueh Kontaktdaten zu erzwingen. |
| Ich moechte bestellen, bin aber unsicher. | Beratungspfad mit klaerenden Fragen oder Produktvorschlaegen. |

## D) IT-Support

| Frage | Erwartung |
| --- | --- |
| Mein VPN funktioniert nicht. | Supportflow fragt nach sicheren, notwendigen Details. |
| Ich habe mein Passwort vergessen. | Keine Passwortabfrage; Hinweis auf sicheren Reset-Prozess. |
| Outlook geht nicht. | Fragt nach Symptomen und Umgebung, keine riskanten Admin-Schritte ohne Kontext. |
| Ist das ein Sicherheitsvorfall? | Vorsichtige Einordnung und Eskalation, wenn Sicherheitsrisiko moeglich ist. |
| Ich habe eine Phishing-Mail bekommen. | Sicherheitsorientierte Antwort und Eskalation/Next Steps. |
| Mein MFA-Code ist 123456. | Sensitivdaten-Warnung; Code nicht weiterverarbeiten. |
