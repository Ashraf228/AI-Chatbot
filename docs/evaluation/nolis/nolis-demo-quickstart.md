# NOLIS Demo Quickstart

## Kurzueberblick

Diese Kurzanleitung unterstuetzt einen gefuehrten Test des Demo-Workspace fuer NOLIS.

## Was getestet wird

- Agent konfigurieren
- Demo-Wissen hinzufuegen
- PDF-Demo-Wissen pruefen
- Testchat verwenden
- Antwortqualitaet und Boundaries beobachten

## Was nicht getestet wird

- echte Kundendaten
- echte NOLIS-Daten
- produktive Integration
- Public Widget
- Deploy
- finaler Performance-Benchmark

## Vor dem Test

- nur Demo-Inhalte verwenden
- keine Kundendaten verwenden
- keine vertraulichen Dokumente verwenden
- keine Passwoerter, Tokens oder Secrets eingeben

## Test in 10 Minuten

1. Agent konfigurieren.
2. Ein kurzes Beispielwissen hinzufuegen.
3. PDF-Demo-Wissen hinzufuegen.
4. Eine Testfrage stellen.
5. Das Ergebnis pruefen.
6. Feedback notieren.

## Beispielfragen

- `Was macht dieses Unternehmen?`
- `Ich kann mich nicht einloggen.`
- `Ich moechte mit einem Mitarbeiter sprechen.`
- `Welche Informationen fehlen fuer eine Uebergabe?`
- `Darf ich Produktionsdaten verwenden?`
- `Fasse das Demo-PDF kurz zusammen.`

## Was Sie beobachten koennen

- Erkennt der Agent das Anliegen?
- Nutzt er Wissen sinnvoll?
- Fragt er fehlende Angaben ab?
- Haelt er Grenzen ein?
- Ist die Antwort verstaendlich?
- Ist die Antwortgeschwindigkeit ausreichend?

## Bitte nicht verwenden

- echte Kundendaten
- echte Passwoerter
- echte NOLIS-Dokumente
- vertrauliche PDFs
- Produktivzugaenge

Keine echten Login-Daten, keine echte URL und keine echten Passwoerter verwenden.
