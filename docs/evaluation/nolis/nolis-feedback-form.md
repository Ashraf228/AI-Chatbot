# NOLIS Feedback Form

## Bitte kurz beantworten

- Was wurde getestet?
- Welche Eingabe wurde gemacht?
- Welche Antwort wurde erwartet?
- Welche Antwort kam?
- War die Antwort hilfreich?
- Wurde Wissen korrekt genutzt?
- Hat der Agent fehlende Angaben sinnvoll abgefragt?
- Wurde korrekt an einen Mitarbeiter eskaliert bzw. simuliert?
- Wurden Grenzen klar eingehalten?
- War die Antwortgeschwindigkeit ausreichend?
- Was fehlt fuer einen echten Pilot?
- Welche Funktion waere fuer NOLIS am wichtigsten?

## Wichtige Hinweise

- keine echten Kundendaten mitschicken
- keine Screenshots mit personenbezogenen Daten senden
- keine vertraulichen Dokumente anhaengen
- Zugangsdaten nicht zuruecksenden
