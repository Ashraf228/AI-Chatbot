# Customer-Facing Demo Caveat Template

## Short Opening Caveat

This is a guided demo of a non-production evaluation workspace.

- no customer data
- no confidential documents
- no production data
- no real ticket, email, or webhook execution
- no production system usage
- response speed and conversation logic are still being optimized
- feedback is welcome

## Placeholder Guidance

Use placeholders only:

- `<demo_workspace_url>`
- `<operator_name>`
- `<evaluation_window>`

- real login URLs
- real passwords
- real names
- concrete time commitments
