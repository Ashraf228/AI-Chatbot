# NOLIS Guided Demo Plan

## Purpose

This plan supports a guided evaluation of the Enterprise Agent Workspace.

It is not a production pilot.
It does not allow customer data.

## Recommended Positioning

The demo shows the planned workflow:

- configure an agent
- add demo knowledge
- ask test questions
- review boundaries

The platform is still being optimized, especially:

- conversation logic
- response speed
- demo usability

## Suggested NOLIS-Like Demo Scenarios

- product-support question
- login or access problem
- question about a software module
- missing details for ticket simulation
- request for human contact
- complaint or dissatisfied user
- privacy or production-data boundary case
- PDF demo knowledge based on a synthetic product sheet

## What To Ask For Feedback

- was the workflow understandable?
- was the answer helpful?
- was the knowledge used sensibly?
- were the boundaries clear?
- which steps felt slow?
- which function is missing for a real pilot?

## Do Not Ask For

- real customer data
- real PDFs
- confidential documents
- productive integration
- access to NOLIS systems
- production secrets

## Recommended Follow-Up

- evaluate the feedback
- prioritize the next gap
- if there is interest, run a separate pilot-approval process
